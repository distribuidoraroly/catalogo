# Distribuidora Roly — Catálogo online

Catálogo digital de insumos gastronómicos de **Distribuidora Roly**, orientado a pizzerías, hamburgueserías, casas de comidas y profesionales gastronómicos.

## Sitio público

**Catálogo:** https://distribuidoraroly.github.io/catalogo/  
**Repositorio:** https://github.com/distribuidoraroly/catalogo

## Funcionalidades

- Catálogo de productos con búsqueda y filtros por categoría.
- Fichas de productos con precios y descripciones.
- Ofertas destacadas.
- Carrito para preparar pedidos.
- Acceso de contacto para consultas y pedidos.
- Diseño adaptable a computadoras y dispositivos móviles.

> Las funciones visibles pueden variar según la versión publicada. Después de cada actualización, conviene probarlas desde el sitio público.

## Cómo se publica

El sitio se publica con **GitHub Pages** desde la rama `main`. El archivo principal debe llamarse exactamente `index.html` y estar en la raíz del repositorio.

## Cómo actualizar el catálogo

1. Guardá una copia de seguridad del `index.html` que funciona antes de editarlo.
2. Hacé los cambios en una copia y probalos en el navegador, tanto en computadora como en celular.
3. Subí el HTML probado como `index.html` en la raíz de la rama `main`.
4. Esperá a que GitHub Pages publique los cambios; puede tardar unos minutos.
5. Abrí https://distribuidoraroly.github.io/catalogo/ y comprobá búsqueda, categorías, ofertas, fichas de producto, carrito y contacto.

## Mantenimiento del repositorio

- Usá `index.html` como única versión publicada.
- Los archivos HTML con nombres alternativos son copias de referencia; no los borres hasta confirmar que no necesitás recuperar contenido de ellos.
- No agregues automatizaciones de despliegue duplicadas que puedan sobrescribir la publicación.
- Si algo deja de funcionar, restaurá la copia de seguridad anterior y volvé a probar.

## Tecnologías

HTML, CSS y JavaScript. El sitio puede cargar tipografías u otros recursos externos, por lo que esas conexiones deben estar disponibles para que se vean correctamente.
