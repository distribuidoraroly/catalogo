# Distribuidora Roly — Catálogo online

Catálogo digital de insumos gastronómicos de **Distribuidora Roly**, orientado a pizzerías, hamburgueserías, casas de comidas y profesionales gastronómicos.

## Sitio público

https://distribuidoraroly.github.io/catalogo/

## Funcionalidades

- Catálogo de productos con búsqueda y filtros por categoría.
- Fichas de productos con precios, descripciones y disponibilidad.
- Sección de ofertas destacadas.
- Carrito para preparar pedidos.
- Acceso de contacto para consultas y pedidos.
- Diseño adaptable a computadoras y dispositivos móviles.

## Publicación

El sitio se publica mediante **GitHub Pages** desde la rama `main`. El archivo de entrada debe llamarse `index.html` y estar en la raíz del repositorio.

## Edición y mantenimiento

1. Editar y probar el HTML antes de publicarlo.
2. Mantener una única versión publicada en `index.html`.
3. Evitar automatizaciones de despliegue duplicadas que puedan sobrescribir cambios.
4. Después de cada commit, comprobar el sitio público y probar búsqueda, filtros, ofertas y carrito.

## Tecnologías

HTML, CSS y JavaScript, con tipografías de Google Fonts.
